Deadline

Label, the date in bold tabular figures, and a countdown pill. Today or tomorrow is red, within 7 days amber, later or rolling grey.
Uses job.days_left as it is today and replaces the urgency badges and the "Rok:" meta text. One tag, deadline job, reused by the card, the job summary and the sticky bar.

Status pill and requirement tag

Five coverage states, each with its own hue and a leading dot, always with a text label. A covered source with zero jobs stays green and shows "0".
Tags are neutral facts read from the advert and never use status colours. A card shows at most three, then "+n"; the job page shows them all.

Job card v2 (second card: hover)

Employer monogram, employer line with "Novo", title linking to the job page, meta row with icons, up to three tags, eligibility as one amber line. The side column holds the deadline and a secondary external link.
The whole card is clickable via a stretched title link; the external button sits above it. Hover raises the border and adds shadow-2, with no movement. Under 640px the side column becomes a footer row. "Detalji i uslovi" goes; "Provjereno" moves to the job page.

Search and filter bar

The primary row holds search, City, Type, Filters (n) and Search. Filters is a details element with organization, scope, education, experience and field; it opens by default when any of them is set. Sort moves to the results header.
Applied chips are plain links built from the current query minus one key, so no JavaScript is needed. The badge counts only hidden active filters. On mobile the search field takes the full row.

Fact row, evidence and notices

Evidence is the product's signature pattern: a quote icon in the summary, a brand rule and italic source text in the advert's language, with an optional source and check-date line. Collapsed by default.
Warning notices (amber, bordered) cover expired jobs and eligibility limits; info notices (neutral) cover translations and filter explanations. Both carry an icon and text, never colour alone.
