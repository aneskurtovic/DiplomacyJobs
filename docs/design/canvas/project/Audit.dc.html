What the site does today

The foundation is strong: honest coverage states, quoted evidence for every extracted requirement, a bilingual interface and no JavaScript dependency. The findings are mostly about hierarchy and density, plus a few real bugs. Screens were captured from a local run with the real 87-organization registry and 8 sample jobs.
